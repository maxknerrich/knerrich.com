# Timing replay

Two measured durations acted out at real speed: the same app, client-server and local-first, side by side.

- Each window's timer counts up for as long as its measurement took; the slower one shows a spinner until then.
- Choosing a row in the floating panel, or replay, starts it over; with reduced motion it shows the end state.
- The corner button shows the numbers as a table in the same space, without the block changing height. Screen readers always get the table.
