# Feature map

What the site does, feature by feature, and what to check. A change to a feature is done when every line of its file holds; never weaken a line to make it pass. **Failing** marks a line the site doesn't meet yet.

Everywhere:

- Works on desktop and phone, with no sideways scroll.
- Reads complete without JavaScript.
- Animations stop for reduced motion.
- Everything but the stickers works by keyboard and screen reader.
- Drafts and seeds publish only in the preview build.
