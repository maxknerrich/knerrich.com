# Bottom bar

A bar floating on every page to switch between work and writing, and to get in touch.

- The key for the current section is pressed in.
- Every page change swaps the key with a click, however it happens: a key, back and forward, a link.
- A new page starts at the top.
- Nothing focused by keyboard ends up under it.
- The keyboard reaches Work, Writing and Contact right after the logo, all inside the Main navigation; the skip link jumps past them.
