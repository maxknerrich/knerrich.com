# tldraw

- Web design
- Design system
- 3D illustration

A minimal website design system and a reusable 3D illustration toolkit for tldraw, an infinite canvas SDK for developers.

Together with [lw.works](https://lw.works/), I redesigned [tldraw.dev](https://tldraw.dev/). My work covered the website's design system and a toolkit for creating the soft, blurred 3D illustrations used across the site.

![3D illustration of a multiplayer canvas with named cursors and a drawing toolbar](/projects/tldraw/multiplayer.png)

## A minimal website design system

I built the design system around two font weights and four core colours. The website was meant to stay minimal, using a small set of shared styles and components across the pages.

![The tldraw.dev homepage, showing its navigation, typography, and canvas SDK introduction](/projects/tldraw/website-home.jpg)

![The tldraw.dev starter kits section, combining a minimal accordion with a 3D illustration](/projects/tldraw/website-starter-kits.jpg)

## A toolkit for 3D illustrations

I created a modular toolkit of reusable 3D elements that could be clicked together into new scenes. This let me build graphics for different features without starting each illustration from scratch, while keeping the same soft, blurred look throughout.
