# Visualisations

Drawings made for one piece, in a shared frame.

- Stepped: step controls, playing through the steps while in view, and links in the text that jump to a step.
- Stepped: a screen reader hears the same name for the drawing at every step, and the current step as its description; a step taken by hand is announced.
- Playing: plays while in view, with Play, Pause and Start over.
